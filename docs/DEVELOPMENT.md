# 开发说明

kai-research 围绕研究论证中的具体判断开展训练。阅读论文时，核对主张由什么证据支持；试写时，检查模型能否把同样的判断落实到结果分析、讨论与审稿回应。反馈写入可加载的规则和教学例。

## 材料与选目

项目与 [kai-writing](https://github.com/ykkai-w/kai-writing) 共享200篇中英文参考论文，其中中文、英文各100篇。200篇是供各项目选择材料的书目范围。本项目的来源依据由17篇论文的阅读与核对记录构成，涉及宏观预测、资产定价、因果识别、组合选择、区间校准和系统评测等问题。

每篇来源卡记录研究问题、主要设计、结果比较、机制解释、反常发现与限制，并注明实际阅读的副本及证据位置。研究论文既提供可学习的论证方式，也提供需要重新审视的主张。对某个局部判断的评价须回到具体表图、公式或设计，不用论文整体声誉替代核对。

## 阅读与核对

来源卡由一名读者整理，再由另一名核对者对照所用论文的页面逐项检查。核对内容包括数值是否准确、页码是否对应、比较对象是否一致，以及作者解释是否超出已经完成的检验。工作论文与正式刊本的差异随副本说明保留，参考位置指向实际阅读的版本。

[来源依据](../references/SOURCES.md)将研究判断与对应论文的具体位置联系起来，并提供完整书目和副本说明。公开文本保留简要评论与必要数值，完整论文和页面图像由原始出版或存储渠道提供。

## 从研究材料形成规范

试写材料保留研究问题、设计、结果表、作者拟作主张及相关意见。写作者依据这些材料与当前规范完成任务，评阅者再检查主结论是否有直接比较、数值与不确定性是否准确、机制解释是否得到相应证据支持。

一项问题可能来自材料提取，也可能来自判断或表达。表格转录错误回到来源核对，比较对象错位回到研究问题，段落里的重复防御则在写作环节处理。修改规范时，保留问题成立的条件，使个案中的经验能够用于相近任务，而不变成所有研究必须遵守的格式。

例如，方法存在检测滞后，仍可能比基准更快；随机实验采用回归，也仍可识别处理效应。规范据此把绝对不足与相对优势、估计方法与识别设计分别判断。另一类问题是原句限定被删掉后再受批评，如将“未显著恶化”理解成“不会恶化”。核对时先保留原句的对象、否定词和限定语，再判断是否需要收缩结论。

## 任务试用

项目进行了有限任务试用，覆盖中英文结果分析、讨论与局限、审稿回应，以及预测、因果识别和方法模拟材料。试用结合论文材料与合成任务。合成任务把待判断的问题写进明确的设计与结果中，便于核对因果依据、比较关系、区间和修改状态。

评阅以实际材料为依据，既检查夸大，也检查有证据的发现是否被写弱。已观察到的表达问题包括遗漏原句限定，以及将分别测试的模型与设计并列后，让读者误以为所有交叉组合都已评估。这些问题对应原句回读和跨表概括的检查。有限试用提供了具体规则的修订依据，公开示例用于展示这些判断怎样进入正文。

## 文件的分工

[SKILL.md](../SKILL.md)提供共同判断与任务入口，结果分析、讨论、回应和研究类型的细节放在 `references/` 中。普通任务从入口开始，需要更细做法时再读取对应参考。中英文例子给出材料、判断与成文，便于读者理解规范的用法。

[示例说明](EXAMPLES.md)展示两个经过编排的合成教学例，分别讨论识别速度与误报的取舍，以及随机实验中的因果措辞与审稿回应。它们与来源论文的简要评论分开标注，便于区分学习依据和教学材料。
