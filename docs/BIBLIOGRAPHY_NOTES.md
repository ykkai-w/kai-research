# 书目来源说明

本目录沿用 kai-writing 与 kaiplot 的200篇中英文参考选目，中文、英文各100篇。书目按发表记录列示，保留作者、题名、年份、载体与 DOI 或正式入口；结构化数据见 [papers.csv](../data/papers.csv)，可按题名或 DOI 与首页参考文献对应。

各项目按任务选择材料。kai-research 的17篇具体学习来源见其来源说明；kai-literature 围绕检索与阅读任务继续补充文献，示例采用的来源另列于使用示例。研究判断依据实际阅读的正文、附录与副本版本。

正式发表信息与实际阅读副本分别记录。工作论文、作者稿与见刊版本之间如有差异，数值和页码跟随所用文本。CSV 的 reference_version_note 保存共享选目的副本说明；DOI 使用已核实记录，其余条目提供期刊或会议入口。既有书目的标识符核验记录见 [kai-writing 书目来源说明](https://github.com/ykkai-w/kai-writing/blob/main/docs/BIBLIOGRAPHY_NOTES.md)。

本目录包括195篇期刊论文、1篇期刊在线提前发表版本、2篇会议论文及2篇预印本。刊物分布反映选目构成，具体任务的阅读范围见各项目开发说明。
